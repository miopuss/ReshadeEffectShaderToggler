# REST Enhanced+ v1.1.1

## 本次修复

- 修复《蓝色星原：旅谣》等 D3D11 游戏在加载插件后运行一段时间闪退的问题：临时设备销毁后，仍然存活的纹理可能稍后触发资源销毁回调，原实现会访问已释放的几何缓冲区跟踪数据并在加锁时崩溃。
- 资源销毁回调先检查设备是否仍然有效；设备清理会等待已经开始的资源回调结束，再移除设备和释放私有数据。
- 保留独立的 D3D11 资源生命周期复现程序，便于回归检查。

## English

- Fix a D3D11 crash when a texture outlives ReShade's device proxy. A late resource-destruction callback previously accessed released geometry-tracking data and crashed while locking its mutex.
- Check device lifetime before resource callbacks access the device or its private data. Wait for callbacks already in progress before device cleanup and ignore callbacks for removed devices.
- Add a standalone D3D11 late-resource regression probe.

## Validation

The original x64 add-on and ReShade 6.8.0 reproduced an access violation in `onDestroyResource`, at `_Mtx_lock+0x13`, in an isolated two-device test that releases a texture after its device proxy. The fixed candidate passes both basic device teardown and late-texture teardown. The maintainer also confirmed that the candidate fixes the reported crash in Azur Promilia (`AzurPromilia.exe`), using D3D11 and ReShade 6.8.0 on x64. Fresh x86 in-game coverage was not recorded. Publication builds and validates x86/x64 in English and Simplified Chinese and runs the existing regression suite.

The manual integration probe is `tests/D3D11LateResourceProbe.cpp`. In a Visual Studio developer shell, compile it with `cl /nologo /EHsc tests/D3D11LateResourceProbe.cpp /Fe:path/to/probe.exe`. Place only the add-on under test beside the executable, run from that directory, and pass the absolute path to an add-on-enabled ReShade DLL: `probe.exe C:\path\to\ReShade64.dll`. Match the probe, ReShade and add-on architectures. Exit code zero and `PASS` indicate successful late-texture teardown; missing add-ons and failed resource creation fail the probe.

Download `release.zh-CN.zip` for Simplified Chinese or `release.zip` for English. Install the add-on matching the game process architecture.
