## 本次更新

- 单个着色器可添加多个索引数范围。一次绘制命中任意范围即可通过索引筛选。
- 在观察列表点击「设为筛选」，会把该索引数追加为精确范围，已有范围和实例数设置会保留。范围可在「几何细节筛选」里编辑或删除。
- README 新增[索引范围与屏幕框选组合用法](https://github.com/miopuss/ReshadeEffectShaderToggler/blob/v1.7.8.680/README.md#combine-index-ranges-and-screen-selection)。已在游戏中验证可将屏幕上分开的两部分 UI 分别保留和隐藏。

下载 `release.zh-CN.zip`（简体中文）或 `release.zip`（English），按游戏进程架构安装一个 `.addon64` 或 `.addon32`。此版本使用 ReShade 6.8 API 基线。

## English

- A shader can match indexed draws against multiple inclusive index-count ranges.
- **Set Filter** on an indexed row appends its count as an exact range and preserves existing instance-count settings. Ranges can be edited or removed in **Geometry Refine Filters**.
- The README explains how to combine index ranges with screen selection. The combined filters were verified in-game with two UI elements in separate areas of the screen.
