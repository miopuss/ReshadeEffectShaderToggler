# REST Enhanced+ v1.0.0

## 本次更新

- 项目更名为 **REST Enhanced+**，版本从 `v1.0.0` 开始，继续使用 ReShade 6.8 / API 20。
- 包含独立 REST 面板、切换组卡片、快捷键表、可搜索的技术项和简体中文界面。
- 支持按着色器隐藏绘制。索引数可匹配多个范围，观察列表可追加精确范围，保留手动设置的实例数条件。支持的 D3D11 和 D3D12 直接索引绘制可显示并筛选去重后的顶点数。
- 支持组合使用索引范围和屏幕框选，只裁掉匹配绘制落在框内的像素。屏幕上分开的 UI 已通过游戏验证。
- 包含上游 Vulkan 场景颜色修复及默认关闭的按游戏场景传输开关。切换后保存并重启游戏生效。

## English

- First release as **REST Enhanced+**, versioned from `v1.0.0` and built against ReShade 6.8 / API 20.
- Includes the dedicated REST panel, group cards, shortcuts, searchable technique routing, and a Simplified Chinese build.
- Per-shader hiding supports multiple index-count ranges, observed-draw presets, instance limits, distinct vertex counts where the index data is available, and screen selection on supported D3D11 and D3D12 direct draws.
- The Vulkan scene-colour fixes and saved scene-transfer preference are included. The preference defaults to off and takes effect after restarting the game.

Download `release.zh-CN.zip` for Simplified Chinese or `release.zip` for English. Install the add-on matching the game process architecture. Existing INI filenames are still recognized.

## English

- A shader can match indexed draws against multiple inclusive index-count ranges.

- The README explains how to combine index ranges with screen selection. The combined filters were verified in-game with two UI elements in separate areas of the screen.

## 本次更新

- D3D11 和 D3D12 的直接索引绘制在能取得索引数据时，会同时显示索引数和去重后的顶点数。点击观察列表该行的「按顶点数筛选」即可应用这个数值。
- 合入上游 Vulkan 场景颜色修复。场景传输开关位于 **REST → 选项 → Vulkan 高级选项**，默认关闭，保存后重启游戏生效。
- D3D12 持续映射、GPU 动态生成的索引和间接绘制暂不提供去重后的顶点数。

下载 `release.zh-CN.zip`（简体中文）或 `release.zip`（English），按游戏进程架构安装一个 `.addon64` 或 `.addon32`。此版本使用 ReShade 6.8 API 基线。

## English

- Supported direct indexed draws on D3D11 and D3D12 show a distinct vertex count alongside the index count. Select **Filter by vertex count** on the observed draw to use that value.
- Integrates upstream Vulkan scene-colour fixes and a per-game scene-transfer preference under **REST → Options → Advanced Vulkan options**. The preference defaults to off and takes effect after saving and restarting.
- D3D12 persistently mapped uploads, GPU-generated indices and indirect draws can leave the distinct vertex count unavailable.

The new D3D12 filtering path has automated regression coverage. In-game validation is pending.

## 本次更新

- REST 现有独立的 ReShade 标签页，提供切换组卡片、快捷键表和可按名称搜索的技术项列表。
- 单个着色器可按索引数、顶点数和实例数隐藏，也可从已观察到的绘制调用填入条件。支持的 D3D11 和 D3D12 直接绘制可使用屏幕框选。
- 新增简体中文界面以及中英文独立安装包。

## 安装

下载 `release.zh-CN.zip`（简体中文）或 `release.zip`（English）。根据游戏进程的架构安装 `.addon64` 或 `.addon32`，每个游戏只安装一个版本。两个语言版本共用原有 INI 配置。在 ReShade 叠加层中打开 **REST**。如果中文显示为方框，在 ReShade 的 **Global font** 中选择支持简体中文的字体。

## English

- Added the dedicated REST overlay, group cards, shortcut table and searchable technique routing.
- Added per-shader hiding by index, vertex and instance counts, with observed-draw presets and region selection for supported direct D3D11 and D3D12 draws.
- Both language packages include x64 and x86 add-ons for the ReShade 6.8 API baseline.

The maintainer reported successful in-game testing of the changes. Specific games, graphics APIs and architectures were not recorded for this test.
