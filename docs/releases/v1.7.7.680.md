## 本次更新

- D3D11 和 D3D12 的直接索引绘制在能取得索引数据时，会同时显示索引数和去重后的顶点数。点击观察列表该行的「按顶点数筛选」即可应用这个数值。
- 合入上游 Vulkan 场景颜色修复。场景传输开关位于 **REST → 选项 → Vulkan 高级选项**，默认关闭，保存后重启游戏生效。
- D3D12 持续映射、GPU 动态生成的索引和间接绘制暂不提供去重后的顶点数。

下载 `release.zh-CN.zip`（简体中文）或 `release.zip`（English），按游戏进程架构安装一个 `.addon64` 或 `.addon32`。此版本使用 ReShade 6.8 API 基线。

## English

- Supported direct indexed draws on D3D11 and D3D12 show a distinct vertex count alongside the index count. Select **Filter by vertex count** on the observed draw to use that value.
- Integrates upstream Vulkan scene-colour fixes and a per-game scene-transfer preference under **REST → Options → Advanced Vulkan options**. The preference defaults to off and takes effect after saving and restarting.
- D3D12 persistently mapped uploads, GPU-generated indices and indirect draws can leave the distinct vertex count unavailable.

The new D3D12 filtering path has automated regression coverage. In-game validation is pending.
