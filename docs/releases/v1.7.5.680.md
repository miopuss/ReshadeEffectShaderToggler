## 本次更新

- REST 现有独立的 ReShade 标签页，提供切换组卡片、快捷键表和可按名称搜索的技术项列表。
- 单个着色器可按索引数、顶点数和实例数隐藏，也可从已观察到的绘制调用填入条件。支持的 D3D11 和 D3D12 直接绘制可使用屏幕框选。
- 新增简体中文界面以及中英文独立安装包。

## 安装

下载 `release.zh-CN.zip`（简体中文）或 `release.zip`（English）。根据游戏进程的架构安装 `.addon64` 或 `.addon32`，每个游戏只安装一个版本。两个语言版本共用原有 INI 配置。在 ReShade 叠加层中打开 **REST**。如果中文显示为方框，在 ReShade 的 **Global font** 中选择支持简体中文的字体。

## Upstream release notes

Vulkan safety and automatic scene-colour matching improvements for ReShade 6.8+.

- Skip manual Vulkan effect rendering inside active passes and on targets without required copy support, avoiding the unsafe Auto Scene Colour off path seen in Enshrouded.
- Extend automatic target matching to same-aspect scene images down to quarter output dimensions, supporting combinations of DLSS/upscaling and reduced render scale. Manual matching modes are unchanged.
- Preserve Vulkan attachment usage instead of automatically adding sampling access where native transient restrictions are unknown.
- Add optional FP16 scene-copy support for eligible images that already support sampling. It stays disabled by default; enable `REST_VULKAN_SCENE_TRANSFERS=1` for the game process before launch and restart. No resource shim may be active. See [setup and limitations](../troubleshooting.md#enshrouded-vulkan-testing) and the [safety review](../vulkan-transfer-safety.md).
- Add an optional bounded Vulkan trace for diagnosing shader targets and safe injection boundaries, disabled during normal use.

## Validation

Both x64 and x86 builds passed automated rendering-safety, lifecycle, shader-hunting, binary and packaging checks. The maintainer confirmed BG3 D3D11/Vulkan and Enshrouded SDR/HDR passes on both Modern v1.7.5.680 and Legacy v1.6.9.580.

Detailed Modern Enshrouded checks also covered DLSS Quality at 100%/67% render scale, group/Auto toggles, shader hunting, a windowed/fullscreen round-trip and clean exit. Legacy's Enshrouded pass was maintainer-reported; individual operations and exact host versions were not separately recorded. See the [validation record](../release-candidate-validation-20261117.md).

Enshrouded's tested setup used `--keep-vulkan-layers`, the optional scene-copy switch and the process-only `RESHADE_DISABLE_GRAPHICS_HOOK=1` exit workaround. Select a suitable earlier scene shader: the final UI draw remains too late for pre-UI effects. These results verify placement and stability in the tested configurations, not HDR colour accuracy or universal Vulkan allocation compatibility. The existing depth-stencil-in-use warning persists. Warframe issue #22 remains separate.
