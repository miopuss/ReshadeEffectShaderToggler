# REST Enhanced+ v1.1.0

## 本次更新

- D3D11 和 D3D12 直接绘制支持按着色器配置多个 VB 筛选，可编辑、删除并保存到配置。VB 标识可能随游戏运行或重启变化。
- 「已观察绘制」按 VB 资源去重，检查全部 32 个输入槽位，列表上限从 32 项提高到 4096 项。默认高度从 85 提高到 280，可拖动底边调整。
- 新增「设为VB筛选」和「设为索引筛选」按钮，均追加到列表并自动去重，保留其他筛选设置。同类列表匹配任意一项，VB 与索引筛选同时启用时需同时满足。
- 着色器中文名添加 PS/VS/CS 缩写，观察行移除累计绘制次数，顶点数不可用时留空。
- 修复 ReShade 主界面关闭后，独立切换组窗口无法操作鼠标的问题。窗口显示期间绘制鼠标并请求输入拦截，关闭后释放该请求。

## English

- Add saved per-shader VB filter lists for direct D3D11 and D3D12 draws, with editing and removal. Native VB identifiers may change during play or between launches.
- Group observed draws by VB resource across all 32 input slots. Increase capacity from 32 to 4096 entries and the initial list height from 85 to 280, with drag-to-resize support.
- **Set VB Filter** and **Set Index Filter** append unique entries while preserving existing filters. Entries within each list are alternatives; enabled VB and index filters must both match.
- Add PS/VS/CS abbreviations to Chinese shader labels. Remove cumulative draw counts from observed rows and omit unavailable vertex counts.
- Restore cursor drawing and input capture for standalone group settings windows after the main ReShade overlay is closed.
- Update both README languages with the current workflow.

## Validation

The maintainer confirmed the final candidate works in their running Client-Win64-Shipping.exe game. The renderer and ReShade version were not recorded. Local x86/x64 CPU regressions cover VB deduplication, multiple filters, 64-bit identifier persistence, cloning and matching. Rendering safety and lifecycle tests pass. Fresh x86 in-game coverage was not recorded. Publication builds and validates both architectures in English and Simplified Chinese.

Download release.zh-CN.zip for Simplified Chinese or release.zip for English. Use the add-on matching the game process architecture and save configuration changes with **Save Changes**.
